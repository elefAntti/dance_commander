# transfer strip renders inline and awaits (DecisionViewModel); these are the APIs that would
# block the whole window on one instead. Enforced as an error by Directory.Build.props (RS0030).

M:System.Windows.Window.ShowDialog;No modal windows: render the decision inline in the pane (DESIGN.md §1.2/2)
T:Microsoft.Win32.OpenFileDialog;Pick files in a pane, not a modal dialog (DESIGN.md §1.2/2)
T:Microsoft.Win32.SaveFileDialog;Pick the target in a pane, not a modal dialog (DESIGN.md §1.2/2)
T:Microsoft.Win32.OpenFolderDialog;Pick the folder in a pane, not a modal dialog (DESIGN.md §1.2/2)
T:Microsoft.VisualBasic.Interaction;InputBox and MsgBox are modal: ask inline instead (DESIGN.md §1.2/2)
