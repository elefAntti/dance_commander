Choosing a file manager

Dance Commander is one of several ways to manage files on Windows, and not the right one for everybody. This page sets it beside the three you are most likely to be weighing it against: Windows' own File Explorer; Total Commander, the two-pane commander that has been around since the nineties; and Directory Opus, the most capable file manager on Windows.

It doesn't list every difference, only the ones that tend to decide the choice. The others were checked against their own pages and manuals in October 2026; if something here has gone out of date, please say so in an issue.

Which one is for you

File Explorer

Stay with it if you open a folder a few times a day, mostly by mouse, and your files live in OneDrive. It is already installed, every program knows how to talk to it, it previews nearly any format through the handlers other programs install, and its search reads inside your documents. What it doesn't do is two folders side by side, servers over SSH, or doing everything from the keyboard.

Total Commander

Pick it if you want the classic two-pane commander at its most complete, for a modest one-off price. Thirty years of features are hard to match: the multi-rename tool, folder synchronisation, a plugin for almost any protocol or format, and it runs on anything Windows has ever run on. The cost is a busy window, a lot of configuration, and decisions asked in dialogs that stop you until you answer.

Directory Opus

Pick it if you want one program that can do everything, and you enjoy shaping a tool to your hand. It is probably the closest to Dance Commander in what it can do, and the furthest from it in temperament: nearly every feature has a preference, a toolbar button or a script behind it. That breadth is real, and so is its price: much of it is rarely needed, hard to remember when it is, and saves only a little time when you do.

Dance Commander

Pick it if you are a developer or look after servers, live on the keyboard, and want the commander's two panes with a browser's address bar, tabs and history. Its strengths are being quiet until you need it, git status in every listing, SFTP servers and archives that behave like any other folder, and the promise that every change can be undone and is never half-written under a real name. It keeps its feature list short on purpose: what isn't used every week doesn't earn a place.

Be honest with yourself about the cost. It is a young product built around the features its author uses and some features are still missing. Content search is coming (grep-style, not indexed), as are pattern rename and SSH keys for SFTP, and it writes only zip archives. If you need FTP, cloud accounts, a plugin for some format or a forty-format preview, one of the other three will serve you better. It is also very likely to still have bugs.

Also worth a look

  • Files: Explorer, modernised. Mouse first, with tabs, tags, an optional second pane, cloud drives in the sidebar and git actions such as switching branches and pushing. Open source.
  • Far Manager: a keyboard-only two-pane commander in a console window, with a strong command line and plugins for servers and archives. Open source.
  • Double Commander: an open-source Total Commander for Windows, Linux and macOS.
  • yazi, lf or Midnight Commander, if you would rather never leave the terminal. They give up Windows' shell, drag and drop and Explorer's menus in exchange.
