Configuration files

Configuration lives in plain files that are meant to be edited by hand, and the application treats them as yours. The settings window (Ctrl+,) is one way of editing settings.json; the file is the other, and each shows what the other did. about:app has a row that opens the folder they are in.

Where things are

In %APPDATA%\DanceCommander\, the files that are about you:

settings.jsonSettings and the keys you have changed. Not written until you change something
tools.jsonYour tools and listings
highlighting.jsonHighlight rules for the listing
bookmarks.jsonBookmarks and their groups
collections.jsonYour collections
history.jsonPlaces you have been, and when
viewstate.jsonEach folder's sort order and whether it shows hidden entries
commands.jsonLines typed at the command line, for ↑ to bring back
palette.jsonWhat you have picked in the command palette, so the usual choice comes first
known_hostsSSH host keys you have accepted

In %LOCALAPPDATA%\DanceCommander\, the things that are about this machine:

DanceCommander.exeThe installed application, with README.md, the licence and the third-party notices beside it
session.jsonOpen tabs and panes, for restoring them
window.jsonWindow position and size
packs.jsonWhich programs with tool packs were found on this computer
logs\The log, one file per day, the last seven kept

Passwords and tokens are kept in Windows Credential Manager, never in any of these files.

Editing them

  • Comments and trailing commas are allowed. Write // why this rule exists wherever it helps.
  • Saving applies it. No restart.
  • A mistake is reported, not punished. If a file doesn't parse, the pane says which file, line and column, and the last good version stays in use. A broken file is never replaced with defaults. If the application needs to save to a file that is broken (adding a bookmark, say), it first copies yours aside as name.broken-<time>.json.
  • Defaults are written only when a file doesn't exist. To get a file's defaults back, rename it and restart. (A new bookmarks.json also takes in Explorer's Quick access pins again; Import bookmarks from Explorer's Quick access in the palette adds pins you don't have yet, without renaming or removing anything.)

settings.json

The settings window writes here, and so can you. It holds only what differs from the defaults, so a missing file, or a missing entry, means the default. A change made in the window touches only its own entry and leaves the rest of the file, comments included, as it was; choosing a default again takes the entry out. Each setting's place in the file is shown under it in the window.

EntryValues
appearance.scheme"system" (follows Windows' app mode, and changes when it does), "dark", "light"
appearance.accent"system" (Windows' accent colour), "blue", "teal", "green", "amber", "red", "pink", "violet", or your own as "#RRGGBB". Whatever it is, its lightness is adjusted until it is legible on the colours in use
appearance.density"comfortable" or "compact" rows
appearance.textSizeA factor over all text and the rows with it: 0.9, 1, 1.1, 1.25
view.directoriesFirsttrue sorts folders before files in a new tab. A folder you sorted another way stays that way
view.cloudStatusWhere a OneDrive file's state is drawn: "cursor" (the cursor row) or "all" (every row, as in Explorer)
commandLine.shell"auto" (Git Bash if installed, otherwise cmd), "bash", "pwsh", "cmd"
mouse.middleClick"newTab" or "otherPane"
tools.packs.idfalse switches a program's tools off (see below)
keys.command idA key of your own for a command, or null for none. See Changing keys
 
// settings.json
{
  "appearance": { "scheme": "light", "accent": "#C2410C" },
  "commandLine": { "shell": "pwsh" },
  "keys": { "dc.search": "Ctrl+F" }
}

When Windows uses a contrast theme, the application uses the theme's own colours, whatever the scheme and accent say.

Tool packs

Some tools come with the programs they run rather than from tools.json. When one of these programs is found, its tools are in the menus; nothing needs adding. The packs, by the id tools.packs uses:

gitbashGit Bash: Open in bash (Ctrl+Shift+B)
terminalWindows Terminal: open it here
wslWSL: open it here
vscodeVS Code: open a file, the folder, or the repository
beyondcompareBeyond Compare: compare marked files, with the other pane, or two folders; git diff; resolving conflicts
fork, gitkrakenOpen the repository in Fork or GitKraken
windowsSHA-256 of a file, with Windows' own certutil

Each pack is switched on or off on the Tools page of Settings, which also says whether its program was found. A tool in tools.json with the same id as a pack's is used instead of it, which is how you change one. A program installed later is noticed the next time the application starts, or when you open the Tools page, and a line in the pane says which tools it added.

Command-line arguments

DanceCommander                      where you left off
DanceCommander PATH                 open PATH
DanceCommander LEFT RIGHT           one place per pane (implies two panes)

DanceCommander /select,PATH         PATH's folder with the cursor on PATH
DanceCommander /n,PATH              PATH in one pane
DanceCommander /e,PATH              PATH in two panes

--select PATH   --left PATH   --right PATH
--one-pane      --two-panes   --new-window   --help

Explorer's syntax is accepted exactly, comma and all, so any program that offers “Show in folder” by calling explorer.exe /select,… can be pointed at Dance Commander instead. A PATH can be any address. A PATH that is a file works too: an archive opens like a folder, and anything else opens its folder with the cursor on it, so Dance Commander can be the program a zip opens with.

If Dance Commander is already running, the arguments are handed to it and open in a new tab, so you don't lose your place. --new-window starts a separate window that doesn't save its session. --help prints to the terminal you typed it in.

The log

%LOCALAPPDATA%\DanceCommander\logs\ is quiet unless something is slow or wrong. Timing lines (Startup:, Slow listing, Slow menu) end with the budget they kept or broke, so if the app ever feels slow, the log says where and by how much. After a crash, the next start says so and points to the log. Include the relevant lines when you report a problem, with the version and commit from about:app.
