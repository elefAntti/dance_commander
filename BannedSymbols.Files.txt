# DESIGN.md §1.6, files are never lost: the calls that delete a file or write over one. Each use
# that remains in src/ sits inside "#pragma warning disable RS0030" with a "§1.6:" comment saying
# why it cannot lose anything, so searching for "§1.6:" gives the complete list to review, and a
# new one cannot arrive unnoticed. Tests are not covered: they make and remove their own files.
#
# Not banned, on purpose: File.Move and File.Copy with two arguments (they never overwrite), and
# FileMode.CreateNew (it fails rather than overwrite). Use those.
